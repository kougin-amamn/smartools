# 決定の履歴

サイト全体に関わる決定を、新しい順に書きます。今の決まりは各文書(`ui.md`・`site.md` や設計書)が正です。ここは、なぜそうなったかを後から追うための記録です。1つの設計書の中だけの決定は、その設計書の「決めてほしいこと」「実装の記録」に書きます。

## 2026-11-17

- 文字の大きさを M3 の type scale(`--type-*`、15段)にそろえた。ばらばらだった 23 種類の大きさを役割に合わせて移した(64px 以上の主役の数字だけ例外)。あわせて、文字の出る所の並びの型(主役→主な操作→補助→結果→説明)を [ui.md](./ui.md) に決めた。

## 2026-11-16

- コンセプトを、サービスコンセプト([service-concept.md](./service-concept.md))とデザインコンセプト([design-concept.md](./design-concept.md))に分けた。デザインコンセプトには Material 3 Expressive の受け止め方を書いた。
- 設定シートのあるツールは、ヘッダを隠していても、つまみの左の歯車の札から1回で設定を開けるようにした。
- カード・パネルの影をやめ、容器の色で分ける形にした(M3)。浮かぶ物と意味のある見せ方だけ影を残す。
- 2つのコンセプトで全ページを点検し、色の名前・角の丸さ・押す所・名前・コントラスト・文字の大きさを直した。決めてほしい事は [concept-review.md](./concept-review.md) の3章。

## 2026-11-15

- M3 の色にした後、カラーテーマが効かなくなっていたのを戻した。テーマの色から M3 の役割の色(主・容器・第三・面の薄い色づけ)を作る形にした。カラーテーマの見直しは後で行い、今は決まりで縛らない。
- 押した時の動きを、全ページ共通の波紋(M3 の ripple、`common/press.js`)にそろえた。ツールごとの縮む・暗くなる動きはやめた。
- ボタンを押すと角が四角くなる動きをやめ、押している間は薄い色を重ねる形にした(見た目が良くないため)。
- 押すと文字が変わるボタンが伸び縮みしないよう、出る文の中でいちばん長い幅にそろえた(`data-texts`)。キッチンタイマーの時間の調整を、M3 Expressive のボタンのまとまりにした(部品を試す最初のツール)。
- 全ツールの主なボタンを大きくした(M3 Expressive。`.pill.primary` は高さ 56px 以上、開始・録音 96px、撮影 80px、再生 72〜80px)。
- ツールのページのヘッダを、初めは隠して右上のつまみで出す形にした(画面を広く使うため)。一覧とランチャーは今のまま。
- デザイン言語を Material 3 Expressive にした。色は M3 の標準の色(紺紫×ミントはやめる)、表現の強さは中くらい、文字は端末の文字のまま。考え方 → 共通部品 → 数ツールで試す順に進める([design/m3-expressive.md](./design/m3-expressive.md))。
- 文書を [OKF](https://github.com/GoogleCloudPlatform/open-knowledge-format) の形にした(各文書の先頭に `type` などの YAML、一覧は `index.md`、履歴はこの `log.md`)。サイトの決まり・設計・決定はこの文書の束を唯一の正とし、AI のメモリには、人と進め方の好みだけを残す。 GitHub でフォルダを開いた時の入口として、`README.md` だけは束の外に残す(`index.md` へ案内するだけ)。
- 一覧の並び順を、表示の切り替えと同じ行の右のプルダウン「並び順」にした(上の行を増やさないため)。表示(一覧・ランチャー)の切り替えもプルダウンにした(小さな画面のため)。一覧の説明の「小さな」を外した。
- 多言語化した(日本語・英語)。言語の切り替えは一覧のページにだけ置く。ツールの中の文・環境情報の表・ランチャーも英語に。日本でしか使わない中身(六曜・祝日・旧漢数字など)は日本語のまま([design/i18n.md](./design/i18n.md))。
- 一覧のカードとツールの見出しから英名を外した(英語の画面があるため。ランチャーは残す)。
- 心拍数計を smartools から消した(ほかへ写したため)。

## 2026-11-14

- デザインコンセプト「使いやすさを、美しく。」を置き、一番上の考え方にした(当時の `design-philosophy.md`。2026-11-16 に [service-concept.md](./service-concept.md) と [design-concept.md](./design-concept.md) に分けた)。配色は紺紫(`#4a4e7a`)×ミントが正しい(ネイビー案から直した)。ランチャーと DJ ツールは例外。
- コンセプトに照らして点検し、直す順番を決めた([concept-review.md](./concept-review.md))。
- 一覧にツールの並べ替え(分類・最近・よく使う・名前)を足した。
- カラーテーマを、自分で用意した6つ(背景まで変える)だけにする案に決めた。ランチャーと一覧は変えない。画面の確認待ち([design/color-theme.md](./design/color-theme.md))。
- 小説読み上げを消した。

## 2026-11-11〜13

- コンセプトの違う、表現の濃いツールは別のサイト [Toolbox Pro](https://github.com/kougin-amamn/toolbox-pro) に置く。DJターンテーブル Pro と DJデッキを移した。

## 2026-11-08

- ページを離れる時の後片付けを `ToolKit.addCleanup` / `addSave` にそろえた([design/page-exit.md](./design/page-exit.md))。
- 名前の決まりを「動詞から始める・取り出しは名詞+Of・略さない」にした([naming.md](./naming.md))。

## 2026-11-07

- アプリや部品を作る前に設計書を書く。設計書はリポジトリの `docs/design/` に置き、Claude Docs には置かない([design/template.md](./design/template.md))。
- ソースの見た目は Prettier でそろえる([format.md](./format.md))。
- ログの仕組みを `common/log.js` にまとめ、ボタンの押下は自動でログに出す。値の変更・選択のログは出さない([logging.md](./logging.md))。
- 共通の部品は `common/` にだけ置き、ツールにコピーしない(前の「ツールごとに1ファイルにまとめる」方針から変えた)([common.md](./common.md))。
- 3D ランチャーの部屋にはサイトの色を使わない。ダッシュボードは消した。

## 2026-11-03〜06

- Cloudflare Workers(静的アセット)で公開する。`main` に入れると公開される([site.md](./site.md))。
- 「オフラインで使える」は目指さない(説明文からも消した)。
- アイコンは紺紫のタイルに平らな色の絵。ミントの丸い印はやめた([ui.md](./ui.md))。

## それより前

- サーバーを使わず、HTML・CSS・JavaScript だけで、見る人の端末で動かす。スマホやタブレットの標準アプリ・ちょっとした道具をそろえる。
- 画像より SVG を使う(通信を軽くするため)。データは `.json` に置く。
- ライト・ダークの両方に対応する(起動時は時間帯で決め、ヘッダのボタンで切り替える)。
