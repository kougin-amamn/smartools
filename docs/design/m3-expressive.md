# Material 3 Expressive に合わせた見た目 設計書

状態: 段 1(共通部品と、一覧・電卓・ストップウォッチ・キッチンタイマー)と段 1b(全ツールの主なボタンを大きく)を試しのブランチ `m3-expressive` で作った。作成 2026-11-15。

## 1. 概要

サイトの見た目を、Google の [Material 3 Expressive](https://design.google/library/expressive-material-design-google-research)(以下 M3E)の考え方にそろえます。M3E は、色・形・大きさ・動き・まとまり(容器)で、大事な操作を目立たせ、関係する物をまとめる考え方です。研究では、大事な部品を見つける速さが最大 4 倍になり、年齢による差も小さくなりました。

- うまくいったと言える目安: どのツールでも、主な操作が一目で分かり、押した時に形と動きで手応えがある。
- 前提(決定 2026-11-15):
  - 進め方: 考え方の文書 → 共通部品 → 数ツールで試して写真を見る → ほかのツールへ広げる。
  - 色: M3 の標準の色(基準の紫 `#6750A4` から作られた色の組)。紺紫×ミントはやめる。
  - 表現の強さ: 中くらい。形(角の丸さの段階)・大きさ・まとまり・ばねの動きを使う。形が変わる動きは押した時だけ。
  - 文字: 端末の文字のまま(通信を増やさない)。大きさと太さの段階だけ M3 に合わせる。
- やらないこと:
  - 決まった形を崩す並べ方(研究で使いやすさが下がった)。文字のラベルを消して絵だけにすること。
  - 動きを減らす設定の人に、動きを見せること(今の `prefers-reduced-motion` の決まりのまま)。
  - フォントの読み込み。

## 2. 基本設計

### 2.1 要件と課題

| 番号 | 要件(受け入れの条件) |
| --- | --- |
| R-01 | 色は M3 の役割(主・第二・第三・面・容器・輪郭・エラー)のトークンで書く。ライトとダークの両方 |
| R-02 | 今のトークン(`--func`・`--accent`・`--fn-bg`・`--panel` など)は M3 の役割の別名にし、手を入れていないツールも M3 の色になる |
| R-03 | 角の丸さは M3 の段階(4・8・12・16・20・28・32・48px・まる)のトークンだけを使う |
| R-04 | 押した時は、全ページ共通の波紋(`common/press.js`)。押した所から丸い波が広がり、離すと消える(さっと叩いても 225ms は見える)。形は変えない(2026-11-15 に、押すと角が四角くなる動きをやめた)。キーボードで押した時は薄い色の層(`--press-layer`) |
| R-05 | ヘッダは面の色(容器)にし、題名は面の上の文字の色。ブランドの色の帯にはしない(M3 の上の帯と同じ) |
| R-06 | 弱い文字(`--sub`)は、面と容器の上で 4.5 以上を保つ |
| R-07 | 動きを減らす設定では、形と位置の動きを止める(色の変化だけ残る) |
| R-08 | 主なボタンは大きい: `.pill.primary` は高さ 56px 以上、丸い主なボタンは 開始・録音 96px、撮影 80px、再生 72〜80px(段 1b、全ツール) |

課題と方針:

| 課題 | 方針 |
| --- | --- |
| 45 ツールが古いトークン名で書かれている | 古い名前を M3 の役割の別名にする(R-02)。ツールの css は手を入れる時に M3 の名前へ移す |
| 角の丸さがツールごとにばらばら(8・10・11・14・18・22px…) | 段階のトークンにする。段 1 は共通部品と試す 3 ツールだけ |
| 押した手応えが `scale(0.92)` だけ | 形が変わる動き(R-04)にする |

採らなかった案:

| 案 | 理由 |
| --- | --- |
| 紺紫を元の色にして M3 の色の組を作る | 決定 2026-11-15: M3 の標準の色にする |
| 表現を強め(大きな見出し・弾む動きを多く) | 決定 2026-11-15: 中くらい。道具のサイトなので、落ち着いた見た目を好む人にも合わせる |
| Roboto Flex を読み込む | 決定 2026-11-15: 端末の文字のまま |

### 2.2 外部仕様

| 場面 | 見える事 |
| --- | --- |
| どのページを開く | 地は薄い紫がかった白(ダークは黒に近い紫)、ヘッダは少し濃い面、主なボタンは紫(`#6750A4`)の まるいボタン |
| ボタンを押す | 押した所から薄い丸い波が広がって消える(形は変わらない)。動きを減らす設定では、広がらずに薄い色が一瞬出る |
| カード・設定シート | 角が大きく丸い(カード 16px・シート 28px) |
| 動きを減らす設定 | 形は変わらず、色だけ変わる |

### 2.4 処理方式

- 置き場所: トークンは `common/site.css` の `:root` と `:root[data-theme='dark']`。部品の形と動きは `common/tool.css`(ツール)と `index.css`(一覧)。
- ばねの動きは CSS の `cubic-bezier`(行き過ぎて戻る曲線)で近づける。M3 の資料の「表現豊か」の値を使う(要確認)。
- カラーテーマ(`themes.json`、確認中)は、今は古いトークンを上書きする。M3 の色の組にするかは、段 2 以降で決める。

## 4. 制限事項と試験

### 4.1 制限事項

- 動きの値は、M3 の資料の値を CSS の曲線に写した物で、Android の本物のばねとは少し違う(要確認)。
- アイコンの地(`#4a4e7a`)は段 1 では変えない(45 個の SVG を描き直すため。段 2 で決める)。
- カラーテーマは、テーマの2色から M3 の役割の色を作って当てる(`site.js` の `tokens`。2026-11-15)。きちんとした M3 の色の組(色調の段階から作る)にするかは、カラーテーマを見直す時に決める。
- 段 1 で手を入れない 41 ツールは、色は M3 になるが、角の丸さは今のまま。

## 6. 実装の記録

### 段 2a: 部品を試す(2026-11-15)

- キッチンタイマーの「−1分・−10秒・+10秒・+1分」を、ボタンのまとまり(connected button group)にした。押したボタンが広がり(`flex-grow`)、角がまるくなり、隣が縮む。
- 押すと文字が変わるボタンの幅を、`data-texts` でいちばん長い文にそろえた(`tool-kit.js` の `keepButtonWidths`。15 ツール)。試験: `node tests/scenarios/button-width.js`。
- 押した時の動きを、全ページ共通の波紋(`common/press.js`。`site.js` が読む)にそろえた。12 ツールにあった `:active` の縮む・暗くなる指定は消した。iPhone の Safari で `:active` が効くよう、触る処理を1つ置く。試験: `node tests/scenarios/press.js`。
