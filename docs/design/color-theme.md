# カラーテーマ(6つのテーマ) 設計書

状態: 確認中(基本設計は決定。画面の写真の確認を待つ)。作成 2026-11-14。

## 1. 概要

ヘッダのカラーボタンで選ぶカラーテーマを、利用者が用意した6つのテーマ(Color Theme Studio の見本)に置き換えます。今までのテーマはボタンなどの色だけを変えましたが、新しいテーマは背景・カード・文字の色まで変えます。

- うまくいったと言える目安: 6つのどれを選んでも、ライトとダークの両方で全ページの文字が読め、選んだ色が全ページにそろう。
- 前提: smartools だけ(Toolbox Pro は今のまま。決定 2026-11-14)。
- やらないこと:
  - アイコン(`#4a4e7a` のタイル)の色を変えること。アイコンは SVG のファイルで、テーマに追従しない。
  - 3D ランチャーの部屋の色を変えること。3D は自分の配色を持つ。
  - ツールごとの css に固定で書いた色を直すこと(見つけたら、手を入れる時に直す)。

## 2. 基本設計

### 2.1 要件と課題

| 番号 | 要件(受け入れの条件) |
| --- | --- |
| R-01 | カラーの一覧に、6つのテーマ(Ocean × Coral、Violet × Lime、Forest × Rose、Sunset Pop、Cyber Yellow、Burgundy × Mint)だけが並ぶ |
| R-02 | テーマを選ぶと、背景・カード・文字・ボタン・アクセント・境界線の色が、そのテーマのライトまたはダークの値になる |
| R-03 | 何も選んでいない時は、01 Ocean × Coral になる。JavaScript が動く前の最初の表示から、この色になる |
| R-04 | 前に今までのテーマ(ブルーなど・標準)を選んで保存していた人は、01 Ocean × Coral になる(エラーにならない) |
| R-05 | ライト⇄ダークの切り替え(今までの仕組み)で、選んだテーマのライト・ダークの値が切り替わる |

課題と方針:

| 課題 | 方針 |
| --- | --- |
| 見本の色の名前(bg・card・button など)と、サイトのトークン(`--bg`・`--panel`・`--accent` など)が違う | 3.2 の対応表で写す。見本の値は `themes.json` にそのまま持つ |
| サイトには境界線と、アクセントを文字に使う時の色のトークンが無い | `--border` と `--accent-text` を足す |
| `ui.md` に「オレンジ・強い赤を使わない」決まりがある | カラーテーマの色は利用者が選ぶ物として、決まりの例外にする(`ui.md` を先に直す) |

採らなかった案:

| 案 | 理由 |
| --- | --- |
| 標準(紺紫×ミント)を残す | 決定 2026-11-14: 新しい6つだけにする |
| 今の15色に足す | 同上 |
| ボタンなどの色だけを変え、背景は共通の灰色のまま | 決定 2026-11-14: 見本どおり背景まで変える |
| Toolbox Pro にも入れる | 決定 2026-11-14: smartools だけ |

### 2.2 外部仕様

- カラーの一覧: `01 Ocean × Coral` 〜 `06 Burgundy × Mint` の6行。各行の色見本は、今のモードのボタンの色とアクセントの色を半分ずつ。
- 選んだテーマは、今までどおり全ページ・全タブで共有する(保存の名前 `site-color` は変えない)。
- ログ: 今までどおり(`カラーテーマを「…」に切り替えました`)。

### 2.4 処理方式

- データ: `common/themes.json` に、テーマごとの `light` と `dark` の色(見本の9つの値)を持つ。
- 最初の色: `site.css` の `:root` と `:root[data-theme="dark"]` に、01 Ocean × Coral の値を書く(JavaScript の前に正しい色にするため)。
- ほかのテーマ: 今までどおり `site.js` が `<style id="site-color">` を足して、トークンを上書きする。
- 保存してあった色に `light` と `dark` が無い(今までのテーマ)時は、上書きしない(= 01 になる)。

## 3. 詳細設計

### 3.1 プログラム構成

| ファイル | 変える事 |
| --- | --- |
| `common/themes.json` | 6つのテーマに置き換える |
| `common/site.css` | 最初の色を 01 Ocean × Coral に。`--border`・`--accent-text` を足す |
| `common/site.js` | テーマの上書きを、見本の値からトークンを作る形に。一覧の色見本を `light`/`dark` から作る |
| `docs/ui.md` | 配色の説明と、オレンジ・赤の決まりの例外 |
| `tests/scenarios/color-theme.js` | 新しいテーマで選ぶ・読み込み直す・最初の色に戻す |

### 3.2 見本の色とサイトのトークンの対応

| サイトのトークン | 見本の値 | 使い道 |
| --- | --- | --- |
| `--bg` | bg | ページの地 |
| `--panel` | card | カード・パネル |
| `--text`・`--fn-fg` | text | 文字 |
| `--sub` | text と bg を 6:4 で混ぜた色 | 弱い文字 |
| `--accent` / `--accent-fg` | button / buttonText | 主なボタン・選ばれた所 |
| `--func` / `--func-fg` | accent / accentInk | 機能の色(ミントだった所) |
| `--fn-bg` | button と card を混ぜた色(ライト 14%、ダーク 24%) | 機能キーなどの淡い面 |
| `--border`(新) | border | 境界線 |
| `--accent-text`(新) | accentText | アクセントを文字に使う時 |
| `--danger` | 変えない | 削除など |

## 4. 制限事項と試験

### 4.1 制限事項

- ツールの css に固定の色を書いている所は、テーマに追従しない。画面の写真で見つかった例: ポモドーロタイマーの輪と再生ボタン(前の標準のミント `#5cc4b6` のまま)、電卓の数字のキー(灰色のまま)。前の標準の色を固定で書いている css は 8 ツールある。
- アイコンのタイルは、どのテーマでも紺紫のまま。
- 文字の読みやすさ(コントラスト)は、見本の作者の値をそのまま使う。全ページでの確認は、画面の写真で目で見る範囲。
