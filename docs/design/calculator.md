# 電卓 設計書

状態: 実装済み(計算の履歴。2026-11-14。実機は要確認)。作成 2026-11-14。前からある部分は、ここには書いていない(四則演算・%・±・桁区切り。`calculator-core.js`)。

## 1. 概要

四則演算とパーセントの電卓に、計算の履歴を足します。表示の窓は一つのまま、履歴は窓の外(上)に出します(決定 2026-11-14)。

- うまくいったと言える目安: さっきの答えを、打ち直さずに次の計算に使える。
- やらないこと: 履歴の編集・並べ替え・書き出し。関数電卓の機能。

## 2. 基本設計

| 番号 | 要件(受け入れの条件) |
| --- | --- |
| R-01 | 表示の窓は一つ。式(小さく)と今の値(大きく)を出す。窓はカードより一段沈んだ面で、ボタンと分ける(2026-11-14) |
| R-02 | = で計算できた時、「式 = 答え」を履歴の最後に足す。0 で割った時(エラー)は足さない |
| R-03 | 履歴は窓の上に、小さな文字で、新しい物を窓に近い下に並べる。見える高さは 3 行分で、古い物は上に送る |
| R-04 | 履歴の行を押すと、その答えが今の入力に入る(計算の途中なら、2 つ目の数として入る) |
| R-05 | 履歴はこの端末に保存し、開き直しても残る。最大 20 件(古い物から消える) |
| R-06 | 「消す」で履歴をまとめて消せる。履歴が無い時は、「消す」を出さず、薄く「計算の履歴」と出す |
| R-07 | 保存できない時(プライベートブラウズなど)も、今の画面の中では履歴が使える |

決定(2026-11-14): 窓は一つ、履歴は窓の外(上)。押すと使える・残す・消す、は AI のおすすめを採用。

### 外部仕様

```
  12 × 3 = 36          ← 押すと 36 が入る
  100 − 25 = 75
                 消す
┌────────────────────┐
│           123 +    │
│              45    │
└────────────────────┘
 [C] [±] [%] [÷] …
```

- 保存: `localStorage` の `calculator-history` に `[{ "expr": "12 × 3", "result": "36" }, …]`(古い順)。
- ログ: 押下は自動。結果は `履歴の答えを使いました(36)`、`履歴を消しました(5件)`。
