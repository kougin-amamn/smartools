# ストップウォッチ

2026-11-17 作り変え(数字とボタンだけの画面 → 輪で時間の経過を見せる画面)。

## 1. 概要

1/100 秒まで計り、ラップ(区間)と合計を記録する。数字を読まなくても、時間が進んでいること・前のラップより速いか遅いかが分かるようにする。

## 2. 基本設計

### 2.1 要件と課題

| 番号 | 要件 | 前の画面の課題 |
| --- | --- | --- |
| R-01 | 時間の経過が目で分かる | 数字だけで、動いているかが分かりにくい |
| R-02 | 開始・停止がいちばん押しやすい | 開始が横長の小さめのボタンで、画面の上にあった |
| R-03 | 押せない時は押せないと分かる | 止まっている時の「ラップ」が押せそうに見えた |
| R-04 | 今のラップが前のラップより速いか遅いかが分かる | 一覧を読まないと分からない |
| R-05 | ラップの一覧で、いちばん速い・遅い区間が分かる(色だけに頼らない) | 印が無い |

### 2.2 外部仕様

画面の並び([ui.md](../ui.md) の型):

1. **主役**: 輪と数字。外の輪は 60 秒で 1 周する(秒針の代わり)。先に丸い印。中に経過時間(display)と、合計の分。
2. **前のラップとの比べ**: ラップが1つ以上ある時だけ、内の細い輪が「今のラップ ÷ 前のラップ」まで伸びる。前のラップを超えたら色を第三の色に変え、中の文に「前のラップより +0.52」と出す(色だけに頼らない)。
3. **主な操作**: 左「リセット」(絵)、真ん中「開始・一時停止」(96px の丸、絵)、右「ラップ」(文字)。
   - リセットは止まっていて 0 でない時だけ押せる。ラップは動いている時だけ押せる。押せない時は薄くし `disabled` にする。
4. **結果**: ラップの一覧(容器)。題「ラップ」、行は番号・区間・合計。2つ以上ある時、いちばん速い行に「最速」、遅い行に「最遅」の札。
5. 横向きは輪を左、操作と一覧を右。

### 2.4 処理方式の要点

- 計時は `stopwatch-core.js`(画面に依存しない)。描くのは `requestAnimationFrame`。
- 輪は SVG の `stroke-dashoffset`(ポモドーロと同じ形)。

## 3. 詳細設計

| 関数(`StopwatchCore`) | 役割 |
| --- | --- |
| `fmt(ms)` | `00:00.00` の文字 |
| `create(now)` | 計時(開始・停止・ラップ・リセット) |
| `secondProgressOf(ms)` | 今の分の中の進み(0〜1) |
| `paceOf(currentSplit, previousSplit)` | `{ ratio, over, difference }`。前のラップに対する今のラップ |
| `extremesOf(laps)` | `{ fastest, slowest }` のラップ番号。2つ未満は null |

## 4. 制限事項・試験

| 番号 | 試験 |
| --- | --- |
| T-01(R-01) | `secondProgressOf` が 0 秒で 0、30 秒で 0.5、60 秒で 0 に戻る |
| T-02(R-04) | `paceOf` が前より短ければ over=false、長ければ over=true と差を返す |
| T-03(R-05) | `extremesOf` が最速・最遅の番号を返し、1つだけなら null |
| T-04(R-03) | 画面: 開く直後はリセットとラップが押せない(smoke) |

- 画面を閉じると記録は消える(前と同じ)。
