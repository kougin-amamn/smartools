# 高度計

2026-11-17 作り直し。外から入った最初の版(1行に詰めた HTML/JS、共通の部品・色・ログ・多言語化を使わない作り)を、サイトの決まりに合わせて作り直した。

## 1. 概要

山歩きや坂道で「ここは海抜何 m か」「さっきの所から何 m 上ったか」を知る。

## 2. 基本設計

### 2.1 要件と前の版の課題

| 番号 | 要件 | 前の版の課題 |
| --- | --- | --- |
| R-01 | 主役は「標高(海抜)」 | GPS の高さ(楕円体高)を主役にしていた。日本では海抜より 30〜40m ほど高く出るので、海抜と取り違える |
| R-02 | 基準の地点からの上り下りが分かる | 「屋外 / 屋内」の切り替えで主役の意味が変わり、分かりにくい。手で基準の高さを打つ欄は、楕円体高の数字を知らないと使えない |
| R-03 | 許可済みなら開いてすぐ測る。まだなら「位置情報を許可」を押してから求める(2026-11-18) | 開いた途端に位置情報の許可を求めた |
| R-04 | 精度が悪い時は、そう分かる | 文だけで、数字の横に出ない |
| R-05 | サイトの決まり(色のトークン・文字の段階・画面の並び・ログ・多言語化・共通ファイルが無い時の案内・アイコン) | どれも無かった |
| R-06 | 位置の扱いが分かる | 送る先が書いていない |

### 2.2 外部仕様

画面の並び([ui.md](../ui.md) の型):

1. **主役**: 「標高(海抜)」と大きな数字(display-large)。下に「地面の高さ(地図のデータ)」と小さく。
2. **主な操作**: 許可がまだの時だけ「位置情報を許可」(許可済みなら開いてすぐ測る)。測っている間は「ここを基準にする」、基準がある時は「基準を解除」。
3. **補助(2枚の札)**: 「基準からの差」(+12.3 m。基準が無い時は「—」と「基準を決めると出ます」)と「GPS の高さ」(楕円体高と ±精度。精度が悪い時は「参考値」の札)。
4. **結果**: 「高さの推移(直近10分)」のグラフ(GPS の高さ)。
5. **案内**: 1行(取得中・許可されない・電波が弱いなど)。
6. **注意**: 標高は約 90m の網目の地図データの地面の高さで、建物の階や細かな起伏は出ない。差は GPS の高さ同士の差なので、海抜とのずれは打ち消される。位置は標高を調べるため約 100m に丸めて Open-Meteo に送り、保存しない。データ: Copernicus DEM GLO-90(Open-Meteo)。

### 2.4 処理方式の要点

- 位置は `navigator.geolocation.watchPosition`(高精度)。画面を離れたら止める。
- 標高は Open-Meteo の elevation API(`https://api.open-meteo.com/v1/elevation`。天気予報と同じ所)。最初と、前に調べた所から 60m 以上動いた時だけ取る。緯度・経度は小数3桁に丸めて送る。
- 計算は `altimeter-core.js`(画面に依存しない)。

## 3. 詳細設計

| 関数(`AltimeterCore`) | 役割 |
| --- | --- |
| `roundedCoordinateOf(v)` | 送る前に小数3桁(約 100m)に丸める |
| `distanceOf(a, b)` | 2点の距離(m) |
| `needsElevationOf(last, now)` | 標高を取り直すか(初めて、または 60m 以上動いた) |
| `elevationUrlOf(lat, lon)` | 標高の問い合わせ先 |
| `qualityOf(accuracy)` | 高さの精度の段階(`good` ≦10m・`fair` ≦30m・`poor`・`unknown`) |
| `signedMetersOf(v)` | 「+12.3 m」の形 |
| `recentOf(history, now, windowMs)` | 推移を直近だけに絞る |

## 4. 制限事項・試験

| 番号 | 試験 |
| --- | --- |
| T-01(R-06) | `roundedCoordinateOf` が小数3桁にする |
| T-02 | `needsElevationOf` が初めてと 60m 以上で true、少しの移動で false |
| T-03(R-04) | `qualityOf` の段階 |
| T-04(R-02) | `signedMetersOf` の符号 |
| T-05(R-03) | 開いた直後は位置を求めない(smoke・画面) |

- 気圧センサーはブラウザから使えないので、高さは GPS と地図のデータだけ。実機の測位・API の応答は sandbox では確かめられない。
