# 頭痛予報 設計書

状態: 実装済み(2026-11-16。実機と本物の Open-Meteo は要確認)。作成 2026-11-16。

## 1. 概要

気圧が下がる時に頭痛が出やすい人が、開くだけで「いつ気をつければよいか」を知るためのツール。現在地(または地名)の1時間ごとの気圧の予報を Open-Meteo の無料API(登録・キー不要)から取り、下がり方の大きさと速さで「安心・注意・警戒」を出す。頭痛が出た時に記録でき、その時の気圧の変化と見比べられる。

- 前提: https(位置情報のため)、外部通信(Open-Meteo)。
- やらないこと:
  - 端末の気圧センサーを読む(ブラウザに気圧センサーを読む仕組みが無い)。
  - 医療の判断・薬の案内(目安であることを画面に書く)。
  - 記録から目安の値を自動で変える(記録が少ないうちは当てにならないため。代わりに感じやすさを3段で選ぶ)。
  - 通知(サーバーが無く、ページを閉じると知らせられない)。

## 2. 基本設計

### 2.1 要件と課題

| 番号 | 要件(受け入れの条件) |
| --- | --- |
| R-01 | 開いた時、現在地の気圧の予報を取り、場所・段階・一言・今の気圧を出す。位置情報が使えない時は地名で探せる |
| R-02 | 1時間ごとに、3時間で下がった量と24時間で下がった量から段階を出す。3時間 1.5hPa か 24時間 6hPa 以上で注意、3時間 3hPa か 24時間 10hPa 以上で警戒 |
| R-03 | 今から24時間で最も高い段階と、最初に注意以上になる時刻を一言で出す(「15時ごろから気圧が下がります」) |
| R-04 | 過去24時間〜48時間先の気圧のグラフに、注意・警戒の時間を帯で、今を縦線で出す。触るとその時間の値を出す。48時間の注意以上の時間を一覧にする |
| R-05 | 感じやすさ(敏感・ふつう・鈍感)を選ぶと、目安の値に 0.7・1・1.4 を掛けて出し直し、次に開いた時も残る |
| R-06 | 「頭痛を記録」を押すと、その時刻を端末に保存する。最近の10件に、その時の段階と変化を出す。7日以内の記録のうち注意以上の時間だった数を出す。1件ずつ消せる |

| 課題 | 方針 |
| --- | --- |
| ブラウザで気圧センサーを読めない | 天気の予報の気圧(`surface_pressure`)を使う。端末の測った値ではないことを制限事項に書く |
| どれくらい下がると頭痛が出るかは人による | 一般によく言われる「短い時間で数hPa下がる」を目安にし、感じやすさで倍率を変える |
| 記録した時の気圧が要る | 予報と一緒に過去7日(`past_days=7`)を取る。それより古い記録は「範囲外」と出す |
| 位置は個人の情報 | 送る位置は 0.01 度(約1km)に丸める。ログに位置・地名を書かない。記録は端末の中だけ |

| 採らなかった案 | 理由 |
| --- | --- |
| 海面気圧(`pressure_msl`)を出す | 変化の量はほぼ同じで、その場所の気圧の方が分かりやすい |
| 記録から目安を自動で学ぶ | 数件では偏る。結果が分かりにくい |
| 設定シートに感じやすさを置く | 設定が1つだけなので、記録の欄に並べる方が見つけやすい |

### 2.2 外部仕様

| 要素 | 操作と結果 |
| --- | --- |
| 地名の欄・検索・現在地ボタン | 検索で候補を5件まで出し、選ぶとその場所で出し直す。現在地ボタンで現在地に戻す |
| 見通しのカード | 場所、段階の札(安心・注意・警戒)、一言、今の気圧と3時間・24時間の変化 |
| 気圧のグラフ | 触る・なぞると、その時間の時刻・気圧・3時間の変化・段階を下に出す |
| 注意する時間の一覧 | 段階の札、始まりと終わりの時刻、3時間で最大どれだけ下がるか |
| 頭痛を記録 | 押すと記録を足し、一覧と数を出し直す。行の × で確認のあと消す |
| 感じやすさ | 3つのうち1つを選ぶ。段階・グラフ・一覧・記録の段階を出し直す |

- 覚えておく物: 記録(最大200件)と感じやすさ。端末の中(localStorage)だけ。
- 外とのやり取り: 位置情報(開いた時に許可を求める)。Open-Meteo の予報(`api.open-meteo.com`)と地名検索(`geocoding-api.open-meteo.com`)。
- 画面に戻った時: 30分以上たっていれば取り直し、そうでなければ「今」の位置だけ直す。
- 失敗した時: 位置が使えない時は理由と「地名で検索してください」、通信できない時は「取得できませんでした。通信状況を確認してください」を下に出す。
- ログ: 予報の取得(時間数・24時間の段階・かかった時間)、地名の検索(件数)、現在地(精度)、記録の追加と削除(件数だけ)。警告: 位置が使えない・地名が無い・保存できない。エラー: 通信の失敗。

### 2.3 デザイン

- スマホ縦の1列(最大 480px)。上から 検索、見通し、グラフと一覧、記録、注意書き。
- 段階の色は `--tertiary` の濃さだけで分ける(安心は面の色、注意は薄い第三の色、警戒は濃い第三の色)。赤やオレンジを使わない(`docs/ui.md`)。色だけに頼らず、札に文字を出す。
- グラフの線は `--primary` の2px、今は破線、目盛りは `--outline-variant`。凡例は 注意・警戒・今。
- アイコン: 明るい横顔に黄色の稲妻。
- 状態: 最初は「現在地を取得中…」だけ。失敗した時は下の文だけで、カードは出さない。記録が無い時は使い方の一文を出す。

### 2.4 処理方式

- 計算は `headache-forecast-core.js`(普通のスクリプト、Node で試験できる)。画面は `headache-forecast.js`。グラフは SVG を文字で組み立てる(ライブラリは使わない)。
- Open-Meteo: `hourly=surface_pressure&past_days=7&forecast_days=3&timeformat=unixtime&timezone=auto`。時刻は Unix 時刻で受け、端末の時刻で出す。
- 画面の文は `lang/en.json` の `tools.headache-forecast.text` で英語にする。

## 3. 詳細設計

### 3.1 プログラム構成

| ファイル | 役割 |
| --- | --- |
| `headache-forecast-core.js` | 下がった量・段階・まとまり・見通し・記録の計算(`window.HeadacheForecastCore`) |
| `headache-forecast.js` | 位置・検索・取得・描画・保存 |
| `headache-forecast.css` | 画面の見た目 |
| `headache-forecast.html` | 画面の部品 |

### 3.2 部品の仕様

| 関数 | 中身 |
| --- | --- |
| `dropOf(pressures, i, hours)` | i 時間目までの hours 時間で下がった量(前が無い時 null) |
| `levelOf(drop3, drop24, sensitivity)` | 0 安心・1 注意・2 警戒 |
| `hourlyLevelsOf(times, pressures, sensitivity)` | `[{time(ms), pressure, drop3, drop24, level}]` |
| `indexAt(hours, ms)` | いちばん近い時間の番号(範囲外 -1) |
| `periodsOf(hours, from, to)` | 注意以上が続くまとまり `[{start, end, level, maxDrop3}]` |
| `outlookOf(hours, now)` | `{now, maxLevel, firstStart, periods}`(今から24時間) |
| `addRecord(records, ms, max)` | 新しい順に足し、上限で切る |
| `recordStatsOf(records, hours)` | `{rows:[{time, hour}], matched, inCaution}` |

### 3.3 データ設計

| キー | 中身 |
| --- | --- |
| `headache-forecast-records` | `[{time: ms}]`(新しい順、最大200件) |
| `headache-forecast-sensitivity` | `high` / `normal` / `low` |

目安の値と倍率は core の定数(`THRESHOLDS`・`SENSITIVITY_FACTORS`)。

## 4. 制限事項と試験

### 4.1 制限事項

- 気圧は予報の値で、端末が測った値ではない。建物の階や、予報の外れは分からない。
- 目安の値は一般的な言い方から決めた物で、医学的に確かめた値ではない。
- 本物の Open-Meteo の返事は、この作業環境からは確かめていない(外へつながらないため)。
