# 多言語化(日本語・英語) 設計書

状態: 段 3 まで公開(2026-11-15。45 ツールすべての中の文を英語に)。作成 2026-11-14。

## 1. 概要

サイトの画面の文を、言語ごとのファイル(`.json`)に分けて、日本語と英語で表示できるようにします。

- うまくいったと言える目安: 英語の端末で開くと、一覧・ヘッダ・ツール名が英語で出る。
- 前提: まず日本語(`ja`)と英語(`en`)。英語は、ほかの言語が無い時の代わりにも使う。ほかの言語は、Cloudflare の訪問者の国を見てから決める(2026-11-14 の相談)。
- やらないこと:
  - ログ(デバッグ画面)の翻訳。作る人向けなので、日本語のまま。
  - 日本でしか使わない中身の翻訳(カレンダーの六曜・旧暦の名前など)。英語の画面でも日本語のまま出してよい。
  - 機械翻訳を画面で動かすこと。訳はファイルに書いておく。

## 2. 基本設計

| 番号 | 要件(受け入れの条件) |
| --- | --- |
| R-01 | 言語ごとに1つのファイル `lang/<言語>.json` を置く。キーはどの言語でも同じ |
| R-02 | 中身は、共通の部品(ヘッダ・メニュー・環境情報・端末の案内)、一覧、分類、注意の札、ツールの名前と説明 |
| R-03 | 最初は端末の言語(`navigator.language`)で選び、ヘッダで切り替えられる。選んだ言語は残す(段 2) |
| R-04 | ファイルに無いキーは、日本語の文を出す(訳し忘れても空にならない)(段 2) |
| R-05 | ツールの中の文は、ツールごとに `lang` の `tools.<slug>` の下に足していく(段 3 以降、ツールに手を入れる時) |

### 進め方

1. **段 1**: `lang/ja.json` と `lang/en.json` を作る(共通・一覧・ツールの名前と説明)。済み
2. **段 2**: `common/i18n.js` で読み込み、ヘッダ・一覧・ツールの見出しに当てる。ヘッダに言語の切り替え。← 今回
3. **段 3**: ツールの中の文を英語に。まず定番の 12 ツール、その後は分類ごとに(決定 2026-11-15)。済み

### キーの形

```json
{
  "site": { "theme": "テーマ", … },
  "list": { "sortRecent": "最近", … },
  "categories": { "定番ツール": "定番ツール", … },
  "tags": { "要 カメラ": "要 カメラ", … },
  "tools": { "calculator": { "title": "電卓", "desc": "四則演算とパーセントの電卓" }, … },
  "environment": { "browser": "ブラウザ", … },
  "device": { "needHttps": "{名前}の利用には https 接続が必要です", … }
}
```

- 分類と注意の札は、今の `index-data.json` の日本語をそのままキーにする(データを変えずに引けるため)。
- `{名前}` のような差し込みは、今のログの書き方(`log.format`)と同じ。

## 3. 詳細設計(段 2)

| ファイル | 変える事 |
| --- | --- |
| `common/i18n.js`(新) | 言語を決める(保存 `site-language` → 無ければ `navigator.language` が ja なら ja、ほかは en)。`lang/<言語>.json` を読み、`data-i18n`(文)と `data-i18n-label`(`aria-label`・`title`)を置き換える。英語ではツールの見出し・題名を `tools.<slug>.title` に。読み終えたら `i18n-ready` の合図 |
| `common/site.js` | `i18n.js` を `document.write` で読む(HTML は変えない)。一覧のヘッダ(`data-language-switch` の付いたページ)にだけ言語のボタン(押すと保存して読み込み直す)。ボタン・メニューにキーを付け、テーマと言語のボタンの名前は `i18n-ready` で付け直す |
| `common/tool-kit.js` | 戻るボタンの名前を `site.backTo` で |
| `common/tool-usage.js` | `agoText(last, now, say)` に訳す関数を渡せる(無ければ日本語) |
| `index.html` / `index.js` | 文に `data-i18n`。ツールの名前・説明・分類・注意の札・件数・日時をその言語に。英語では英名の添え字を出さない |
| `tests/lib/harness.js` | 試験の端末の言語を `ja-JP` に(`opts.locale` で変えられる) |
| `tests/scenarios/i18n.js`(新) | 英語の端末・切り替え・日本語の端末 |

- `window.I18n`: `language`、`t(キー, 差し込み, 日本語の文)`、`apply(範囲)`、`ready`(Promise)、`isReady()`、`setLanguage(言語)`。
- ログ・`data-log` は日本語のまま(ログは訳さない)。
- 言語のファイルが読めない時は、日本語のまま表示し、警告のログを出す。

## 3.2 詳細設計(段 3: ツールの中の文)

方針: ツールの js をなるべく変えずに訳す。訳は「日本語の文 → 英語の文」の対応表にし、画面に出た文を置き換える。

| 物 | 書き方 |
| --- | --- |
| 対応表 | `en.json` の `tools.<slug>.text` に `{ "日本語の文": "英語の文" }`。日本語の文がそのままキー(`ja.json` には書かない) |
| 差し込みのある文 | キーに `{名前}` を書く(例 `"{数}回"` → `"{数} times"`)。差し込まれた値も、対応表にあれば訳す(例 曜日の `"日"` → `"Sun"`) |
| 画面の文 | `i18n.js` が、英語の時だけ、本文の文字(要素の中の文1つ分がまるごと一致する物)と `aria-label`・`title`・`placeholder` を置き換える。後から js が書いた文も、`MutationObserver` で見て置き換える |
| 画面に出ない文(canvas に描く文字・確認の窓など) | ツールの js で `I18n.say('日本語の文', { 名前: 値 })` |
| 共通の部品(`device.js`・`env.js`)が出す文 | `en.json` の `text`(全ツールで使う。ツールの表に同じ文があればツールの方) |
| 英語の名前を元から持っている物(物体検出・画像判定の物の名前、ピアノのコード) | 英語の画面では、日本語の名前の表を使わず英語のまま出す(ツールの js で `I18n.language` を見る) |
| 差し込みの値が空のこと | 差し込みは空でもよい(例「物を{範囲}大きく写すと…」) |
| HTML の中で折り返した長い文 | 空白をまとめて1つにしてから引く(キーも空白1つで書く) |
| 訳さない所 | `script`・`style`・入力欄(`textarea`・`input` の値)・`contenteditable`・`data-i18n-skip` の付いた要素の中。ログ |

- 日本語の時は何もしない(置き換えも見張りもしない)。
- 試験(`lang.test.js`): `text` のキーが、そのツールの html・js に本当にあるか(訳が古くなっていないか)。

### 進め方(段 3)

1. 定番の 12 ツール(電卓・メモ帳・天気・ライト・ストップウォッチ・キッチンタイマー・ポモドーロ・世界時計・アナログ時計・デジタル時計・数取り・カレンダー)。
2. 残りを分類ごとに。

## 4. 制限事項

- 英語の訳は AI が書いた。言い回しは、使いながら直す。
- 環境情報の表、ランチャーの名前(`launchers.json`)は日本語のまま。
- 英語の画面では、押したボタンのログの名前が英語になることがある(`data-log` の無いボタンは、画面の名前をログに使うため)。
- 試験で確かめたのは、開いた直後の画面だけ。押した後やエラーの時の文は、対応表とツールの文が合っていることを試験で確かめている。
- 文の一部だけが別の要素に分かれている所(例 `<b>3</b>回`)は、まるごとの一致にならないので、js で `I18n.say` を使う。
- 言語のボタンは一覧のページだけに出す(ツールのヘッダを狭くしないため。決定 2026-11-15)。選んだ言語は全ページで使う。
- 言語を切り替えると、ページを読み込み直す(入力中の内容は各ツールの保存に任せる)。
