# ツールの並べ替え 設計書

状態: 確認中(画面の写真の確認を待つ)。作成 2026-11-14。

## 1. 概要

一覧のツールを、分類順・最近使った順・よく使う順・名前順に並べ替えられるようにします。そのために、ツールを開いた日時と回数を、その端末のブラウザに記録します。

- うまくいったと言える目安: よく使うツールが、一覧のいちばん上から開ける。
- 前提: 記録はその端末・そのブラウザの中だけ(`localStorage`)。サーバーには送らない。別の端末とは共有しない。
- やらないこと:
  - ランチャー(デスクトップ・3D本棚・3D美術館)の並び(決定 2026-11-14: 一覧だけ)。
  - 記録を消すボタン。ブラウザのサイトのデータを消すと消える。
  - 検索(コンセプトの点検の B-2。別に考える)。

## 2. 基本設計

### 2.1 要件

| 番号 | 要件(受け入れの条件) |
| --- | --- |
| R-01 | ツールのページを開くたびに、そのツールの「最後に開いた日時」と「開いた回数」を記録する。ランチャーの中で開いた時(埋め込み)も数える |
| R-02 | 一覧の上に「並び」の切り替え(分類・最近・よく使う・名前)を置く。選んだ並びは、次に一覧を開いた時も残る |
| R-03 | 分類: 今と同じ(分類の見出しごと、index-data.json の順) |
| R-04 | 最近: 分類の見出しを外して1列にし、最後に開いた日時が新しい順。まだ開いていないツールは後ろに、分類の順で並べる |
| R-05 | よく使う: 同じく1列で、開いた回数が多い順(同じ回数なら最近の順)。まだ開いていないツールは後ろ |
| R-06 | 名前: 1列で、名前の あいうえお順 |
| R-07 | 最近の時はカードに「3時間前」など、よく使う時は「12回」を小さく出す。分類・名前の時は出さない |
| R-08 | 記録が読めない・壊れている時(プライベートブラウズなど)も、一覧は分類の順で表示できる |

決まった事: 一覧だけ・1列にする・並べ替えた時だけ日時と回数を出す(2026-11-14)。名前順は「など」の一つとして AI が足した。

### 2.2 外部仕様

```
表示  [一覧] [デスクトップ] [3D本棚] [3D美術館]
並び  [分類] [最近] [よく使う] [名前]
```

- 「並び」は、今の「表示」と同じ形の丸いボタンを並べる。選んでいる物に印(`aria-pressed`)。
- 日時の出し方: 1分未満は「たった今」、1時間未満は「◯分前」、1日未満は「◯時間前」、7日未満は「◯日前」、それより前は「11月3日」。
- ログ: ボタンの押下は自動のログ(「並び」の「最近」ボタンを押下しました)。並べ替えた結果のログは出さない(値の切り替えのため。サイトの決まり)。

### 2.4 処理方式

- 記録と並べ替えの計算は `common/tool-usage.js`(`window.ToolUsage`)。DOM を使わず Node で試せる。
- ツールのページ: `tool-kit.js` が `tool-usage.js` を読み込み、ページの場所(`tools/<slug>/`)から名前を取って記録する。各ツールは何も書かない。
- 一覧: `index.html` が `tool-usage.js` を読み、`index.js` が並べ替える。
- 記録の形: `localStorage` の `tool-usage` に `{ "<slug>": { "count": 回数, "last": ミリ秒 } }`。

## 4. 制限事項と試験

- 記録は端末・ブラウザごと。スマホとパソコンでは別々。
- ページを読み込み直しても 1 回と数える。
- 試験: 3 章の2つと、`node tests/smoke.js all`。
