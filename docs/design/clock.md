# 時計

2026-11-17 アナログ時計(`tools/analog-clock/`)とデジタル時計(`tools/digital-clock/`)を1つにまとめた。

## 1. 概要

今の時刻を、アナログかデジタルの好きな形で大きく出す。どちらも見た目(文字・色・フォント・フレーム)を選べる。

## 2. 基本設計

### 2.1 要件

| 番号 | 要件 |
| --- | --- |
| R-01 | 1つのツールで、アナログとデジタルを切り替えられる |
| R-02 | 選んだ表示と、それぞれの見た目の設定は端末に残る(前のツールの設定も引き継ぐ) |
| R-03 | 前の2つのページのブックマーク・共有リンクから、同じ表示で開ける |

### 2.2 外部仕様

- 画面は時計だけ(主役)。設定は右上の歯車の札から開く。
- 設定シートのいちばん上に「表示: アナログ / デジタル」の切り替え。その下に、選んでいる表示の設定だけを出す(アナログ: おすすめテンプレートと詳細設定、デジタル: 表示形式・文字色・フォント・文字サイズ・背景色・フレーム)。初期設定に戻すボタンは表示ごと。
- `?mode=analog` / `?mode=digital` で表示を決めて開ける。無い時は前に選んだ表示、初めてはアナログ。
- 前のページ `tools/analog-clock/analog-clock.html` と `tools/digital-clock/digital-clock.html` は、それぞれ `?mode=analog` / `?mode=digital` を付けて時計へ移る(検索の文字や `#` もそのまま引き継ぐ)。

### 2.4 処理方式の要点

| ファイル | 役割 |
| --- | --- |
| `clock.js` | 表示の切り替え・保存(`clock-mode`)・起動のログ |
| `analog-clock.js` / `analog-clock-core.js` | アナログの描画と設定(保存 `analog-clock-settings`、前のまま) |
| `digital-clock.js` / `digital-clock-core.js` | デジタルの描画と設定(保存 `digital-clock-settings`、前のまま) |

- 2つの表示は同じページにあるので、設定の部品の id は `analog…` / `digital…` で分ける。
- 隠れている時はデジタルの文字の大きさを測れないので、切り替えた時に `resize` を出して測り直させる。

## 4. 制限事項・試験

| 番号 | 試験 |
| --- | --- |
| T-01(R-01) | 設定で切り替えると、時計と設定の中身が入れ替わる(画面で確認) |
| T-02(R-03) | 前のデジタル時計のページを開くと `clock.html?mode=digital` に移り、デジタルが見える(画面で確認) |
| T-03 | `node tests/smoke.js tools/clock` |

- 時計は2つとも動き続ける(隠れている方も1秒ごとに描く)。軽いので分けていない。
