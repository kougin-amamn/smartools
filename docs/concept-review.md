# コンセプトに照らした点検(2026-11-16)

[サービスコンセプト](./service-concept.md)と[デザインコンセプト](./design-concept.md)(Material 3 Expressive に沿う)を物差しにして、一覧・デスクトップのランチャー・47 のツールを点検しました。前回(2026-11-14)の点検は git の履歴にあります。

## 1. 点検のしかた

- **自動で測った物**: 49 ページを、幅 360px のライトとダークで開いて測った(押す所が 44px 未満、名前の無い操作、文字のコントラスト、11px 未満の文字、横のはみ出し、開いた時のエラー)。
- **ソースで数えた物**: ツールの css の固定の色(`#xxxxxx`)、古い色の名前、段階でない角の丸さ、影。
- **測っていない物**: 実機での操作感、画面の読み上げ、3D ランチャーの中、CDN のライブラリを使うツールの中身。

## 2. 直した事(2026-11-16)

| 番号 | コンセプト | 直した事 |
| --- | --- | --- |
| F-1 | デザイン 3.2(色は役割の名前) | 45 のツールと一覧の css の古い色の名前(465 か所)(`--func` など)を、M3 の役割の名前(`--primary` など)に置き換えた。値は同じなので見た目は変わらない |
| F-2 | デザイン 3.1(角の丸さは段階だけ) | ツールの角の丸さ(8・10・11・14・18・22px など 159 か所)を、いちばん近い M3 の段階のトークンにした |
| F-3 | デザイン 3.3(押す所 44px) | 共通の css で、ボタン(`.pill`・`.round`)・選ぶ欄・文字の入力欄を 44px 以上にした。札(`.chip`)は見た目はそのまま、押せる所だけ上下に広げた(M3 の chip と同じ)。ポモドーロの ±(28px)、世界時計の削除(32px)、頭痛予報の切り替え(40px)、タブ、一覧の選ぶ欄も 44px に |
| F-4 | サービス 2.2(支援技術) | 名前の無かったスライダーとファイルの選択(手鏡・画像ビューア・メトロノーム・音楽・ナイトカメラ・OCR・読み上げ・動画の 13 個)に名前を付けた(英語の訳も) |
| F-5 | デザイン 3.2(コントラスト) | 数取器のリセット(4.0)、ポモドーロの「作業」(2.0)、カレンダーの大安(2.1)・祝日の文字(3.9)・祝日の札(ダーク 1.7)を、M3 の色の役割にして 4.5 以上にした。ポモドーロは作業=主、休憩=第三の色に |
| F-6 | デザイン 3.2(読める文字) | 10px の文字(カレンダーの六曜・ピアノ・歩数計・画像ビューア・Exif・頭痛予報)を 11px(M3 の小さなラベルの下限)にした |
| F-7 | 決まり(ライブラリは版を決める) | デバッグ画面(eruda)を版を決めずに読んでいたので、`eruda@3.4.3` にした |

## 3. 決めてほしい事

| 番号 | 何を | 今の状態 | 案 |
| --- | --- | --- | --- |
| Q-1 | **配色** | いただいたコンセプトの文は「ネイビー中心+ミント」。2026-11-15 に「M3 の標準の色(紫)」に決めて実装済み。デザインコンセプトは M3 の色で書いた | (a) M3 の標準の色のまま(おすすめ。M3E と食い違わない)/(b) ネイビーを元の色にして M3 の色の組を作る |
| Q-2 | **影** | 40 のツールに、カードやパネルの影(`box-shadow`)が残っている。M3 は平らな面と容器の色で分けるのが基本 | 影を消して容器の色で分ける(カメラの上に浮かぶボタンなど、映像の上の物だけ残す) |
| Q-3 | **固定の色**(119 か所) | 映像の上の白・黒(カメラ・動画)、カレンダーの土曜の青・一粒万倍日の金・天赦日の紫、ピアノの鍵盤、DJ、方位磁石、デジタル時計の色の見本など | 意味のある色(土曜・鍵盤・映像の上)は残し、それ以外を役割の色にする。どれを残すかを決めたい |
| Q-4 | **アイコンの地の色** | 47 個とも紺紫(`#4a4e7a`)のまま | (a) M3 の紫(b) 薄い容器の色に紫の絵(c) このまま |
| Q-5 | **小さな札** | カメラのフィルター・画像加工・レンズの札は、見た目 33px(押せる所は 44px に広げた) | このまま(M3 と同じ)/見た目も 44px に |
| Q-6 | **お絵かき** | 道具の列 38px・色の見本 28px(描く場所を広く取るための例外) | 例外のまま/色の見本だけ大きく |
| Q-7 | **DJターンテーブル(簡単な方)** | Pro と DJデッキは Toolbox Pro へ移したが、簡単な方は smartools に残っている。機器を模した見た目・固定の色が多い | smartools に残して例外とする/Toolbox Pro へ移す |
| Q-8 | **設定(歯車)** | ヘッダを隠したので、設定のあるツール(時計2つ・ピアノ・マルチカメラ)は2回押す | 歯車だけ外に出す/このまま |
| Q-9 | **M3E の部品** | ボタンのまとまりはキッチンタイマーだけ | 次に、AI のツールの読み込みを M3E の進み具合の印に、音楽・動画の操作を浮かぶ帯に |
| Q-10 | **文字の段階** | 見出し・本文・ラベルの大きさがツールごとにばらばら | M3 の文字の段階(22・16・14・12px など)のトークンを作り、ツールを手直しする時に移す |
| Q-11 | **カラーテーマ** | テーマの2色から M3 の役割の色を作る仮の形 | 見直しの時に決める(保留中) |
