# コンセプトに照らした点検(2026-11-14)

状態: A-1・A-2・A-3 を直した(2026-11-14)。ほかは未着手。

[design-philosophy.md](./design-philosophy.md)(使いやすさを、美しく。)を物差しにして、サイト全体を点検した結果です。直す順番は、コンセプトの「デザイン判断の優先順位」(3.2)に合わせました。

## 1. 点検のしかた

- **自動で測った物**: 一覧・デスクトップのランチャー・46 のツールの 48 ページを、スマホの幅(360px)のライトとダークで開いて測った。
  - 横にはみ出すか
  - 押す所の大きさ
  - 名前の無いボタン・入力
  - 文字と背景のコントラスト(WCAG の基準: ふつうの文字 4.5、大きい文字 3)
  - 開いた時のエラー
- **読んで照らした物**: 一覧・ランチャー・ヘッダ・共通の部品・文書を、コンセプトの各章(2〜6 章)と照らした。
- **測っていない物**: 実機での操作感、画面の読み上げ(スクリーンリーダー)、3D ランチャーの中、CDN のライブラリを使うツールの中身(開発環境では動かないため)。

## 2. できている所

| コンセプト | 今の状態 |
| --- | --- |
| インストールなし(2.1) | 登録・ログイン・インストールは一つも無い。開けばすぐ使える |
| 適応性(3.1 の 4) | 48 ページすべて、スマホの幅で横にはみ出さない |
| 実用的(2.4) | 48 ページすべて、開いた時にエラーが無い。失敗は画面とログで伝える決まりがある |
| 明快さ(3.1 の 2) | 名前の無いボタンは 0。押した事はすべてログに残る |
| 一貫性(3.1 の 3) | ヘッダ・設定シート・ボタンの形・ログの書き方が共通の部品でそろっている |

## 3. 直したい所

優先度: **高** = アクセシビリティ(3.2 の 2 番目)に関わり、多くのページに出る。**中** = 迷わない・一貫性に関わる。**低** = 個別のツール、または見た目。

### 3.1 アクセシビリティ(2.2 ユニバーサルデザイン)

| 番号 | 優先度 | 見つかった事 | 直し方の案 |
| --- | --- | --- | --- |
| A-1 | 高 | **弱い文字(`--sub`)のコントラストが足りない。** ライトで 41 ページ。`#7a7d8a` は地 `#f5f5f7` に対して 3.8、白いカードの上で 4.1(基準は 4.5)。英名・説明・件数などに使っている | 直した: `--sub` をライト `#62656f`・ダーク `#9598a9` に(地・面・ティントの上で 4.5 以上) |
| A-2 | 高 | **ヘッダのボタンが 30×30px と小さい。** 全ページの 4 つ(環境情報・カラー・テーマ・デバッグ)と、設定の歯車(8 ツール)。指で押すには、44px 前後が目安 | 直した: 絵はそのまま、押せる範囲を高さ 44px・幅 38px に(幅を 44px にすると題名が折り返したため 38px) |
| A-3 | 中 | **動きを抑える設定に、ほとんど応えていない。** 対応は 2 か所(設定シート・一覧のカード)だけ。CSS の動きがあるツールは 13、描き続けるツールは 16 | 直した: `site.css` で animation・transition を止める。キッチンタイマーの時間切れは、点滅の代わりに知らせの色のままにする |
| A-4 | 中 | **名前の無い入力** が 12 ツール(読み上げ・手鏡・ナイトカメラ・音楽・動画・メトロノーム・OCR・天気など) | `label` か `aria-label` を付ける |
| A-5 | 中 | **小さいチェックボックス・リンク**: 数取器・ナイトカメラ・歩数計・世界時計のチェックボックス(13px)、通信速度のリンク(高さ 14px)、カレンダーの「今日」(高さ 21px)、ポモドーロの −/+(28px) | 文字ごと押せるようにする・大きくする |
| A-6 | 低 | **個別のコントラスト不足**: 物体検出の「AIの準備をしています」(1.2)、色の取り出しの「--」(1.9)、カレンダーのダークの「元日」(2.5)、Exif の「exifr」のリンク(1.9) | それぞれの色を直す |

## 4. 進め方の案

1. **共通の部品だけで直せる所**(A-1・A-2・A-3)を先に直す。ファイルの数が少なく、全ページに効く。
2. **決めてほしい事**(B-1・B-2・B-3・C-1・C-4)を決める。
3. **配色の作り直し**(C-2)。ここで C-3 も合わせて直す。前のカラーテーマの案(`color-theme` ブランチ)は使わずに閉じる。
4. **個別のツール**(A-4・A-5・A-6)は、まとめて直すか、手を入れる時に直す。
