ファイル転送File Transfer

2台のスマホで、片方が「番号を出す」、もう片方が「番号で参加」を押してください。

接続の番号

------

相手のカメラでQRコードを読むか、番号を入れてもらってください。

「」から接続の申し込みがあります。

「」とつながっています

    送ったファイル・受け取ったファイルがここに並びます

    ファイルはサーバーを通らず、端末どうしの暗号化された通信で直接届きます(つなぐ相手を見つける時だけ、PeerJS の公開サーバーを使います)。2台を同じWi-Fiにつなぐと確実です。携帯回線どうしではつながらないことがあります。受け取ったファイルはいったん端末のメモリに置くため、スマホでは1ファイル数百MB〜1GB程度までが目安です。転送中は画面を開いたままにしてください。
