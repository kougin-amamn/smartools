ファイル転送File Transfer

2台のスマホで、片方が「番号を出す」、もう片方が「番号で参加」を押してください。

接続の番号

------

相手のカメラでQRコードを読むか、番号を入れてもらってください。

「」から接続の申し込みがあります。

相手の画面の確認番号と同じなら許可してください。違う時は断ってください。

「」

    送ったファイル・受け取ったファイルがここに並びます

    ファイルは端末どうしの暗号化された通信(WebRTC)で直接届きます。つなぐ相手を見つける時だけ PeerJS の公開サーバーを使い、直接つながらない時は PeerJS の中継サーバーを通りますが、どちらも中身は読めません。両方の画面の確認番号が同じなら、間に誰も入っていません。つなぐ時、お互いのIPアドレスが相手と待ち合わせ用のサーバーに伝わります。文字の多いファイルは自動で圧縮して送ります。途中で切れた時は60秒まで自動でつなぎ直して続きから送り、それでもだめな時は、もう一度つないで「再送」を押すと続きから送れます(どちらかのページを閉じると最初からになります)。受け取ったファイルはいったん端末のメモリに置くため、スマホでは1ファイル数百MB〜1GB程度までが目安です。転送中は画面を開いたままにしてください。
